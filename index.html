Pourquoi Cloudinary ? ☁️

1. Stockage : Mes images sont stockées dans le cloud, pas dans le projet GitHub.

2. Optimisation : f_auto choisit le meilleur format (WebP/AVIF) et q_auto réduit le poids sans perdre la qualité.

3. Redimensionnement : w_800 affiche l'image en 800px, parfait pour mobile et ordinateur.

4. CDN : Les images sont servies depuis le CDN de Cloudinary, donc le site charge très vite partout dans le monde.
