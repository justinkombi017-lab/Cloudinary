## Description
Site statique simple qui affiche une galerie de 3 images. 
Aucune image n'est stockée dans ce dépôt, toutes les images sont hébergées sur Cloudinary.

## Technologies utilisées
- HTML5
- CSS3 (Grid, Flexbox, Responsive)
- Cloudinary (hébergement + optimisation d'images)
- GitHub Pages (hébergement du site)

## Pourquoi Cloudinary ?
1. **Stockage :** Les images sont uploadées dans la Media Library de Cloudinary.
2. **Optimisation automatique :** `f_auto,q_auto` dans l'URL choisit le meilleur format et compresse sans perte visible.
3. **Redimensionnement :** `w_800` redimensionne à 800px pour un chargement rapide.
4. **CDN :** Les images sont distribuées via le CDN de Cloudinary.
